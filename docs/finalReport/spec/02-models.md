## 2.2 模型一：線性回歸 (Linear Regression)

### 2.2.1 模型原理

```
AQI = β₀ + β₁(windspeed) + β₂(季節) + β₃(PM2.5) + ... + ε
```

最小化均方誤差 (MSE) 來求解係數 β。

### 2.2.2 實作規格

| 項目 | 規格 |
|------|------|
| **套件** | `sklearn.linear_model.LinearRegression` |
| **輸入特徵** | windspeed, season, month, hour, pm2.5, pm10, o3 |
| **目標變數** | aqi (連續值) |
| **評估指標** | R², RMSE, MAE |

### 2.2.3 預期產出

1. **係數表**：量化各因素對 AQI 的影響
   - 例：β₁ = -5.3 → 風速每增加 1 m/s，AQI 下降 5.3 點
2. **模型準確度**：R²（決定係數）
3. **預測 vs 實際散點圖**

### 2.2.4 與期中報告連結

期中發現「AQI 隨風速增加而下降」→ 回歸係數 β₁ < 0 驗證此發現

## 2.3 模型二：決策樹 (Decision Tree)

### 2.3.1 模型原理

建立 IF-THEN-ELSE 規則樹，自動學習分類邊界。

使用 **Gini 不純度** 或 **資訊增益 (Entropy)** 選擇分割點。

### 2.3.2 實作規格

| 項目 | 規格 |
|------|------|
| **套件** | `sklearn.tree.DecisionTreeClassifier` |
| **輸入特徵** | windspeed, season, month, hour, county |
| **目標變數** | aqi_level (良好/普通/不健康) |
| **超參數** | max_depth=5（限制深度便於可視化）|
| **評估指標** | Accuracy, Confusion Matrix |

### 2.3.3 預期產出

1. **決策樹圖**：可視化分類規則
   ```
             [windspeed ≤ 1.5?]
               /           \
            Yes             No
             |               |
      [season = 冬季?]    「良好」
        /        \
      Yes        No
       |          |
   「不健康」   「普通」
   ```
2. **混淆矩陣**：分類準確度
3. **特徵重要性**：哪個變數最重要

### 2.3.4 與期中報告連結

期中的二維交叉統計表 → 決策樹自動學習類似規則

---

## 2.4 模型三：隨機森林 (Random Forest)

### 2.4.1 模型原理

多棵決策樹的集成 (Ensemble)，透過投票機制提高準確度。

### 2.4.2 實作規格

| 項目 | 規格 |
|------|------|
| **套件** | `sklearn.ensemble.RandomForestClassifier` |
| **輸入特徵** | 同決策樹 |
| **目標變數** | aqi_level |
| **超參數** | n_estimators=100, max_depth=10 |
| **評估指標** | Accuracy, F1-Score |

### 2.4.3 預期產出

1. **準確度比較**：與決策樹對比
2. **特徵重要性排名圖**
   ```
   Feature Importance:
   1. windspeed: 0.35
   2. season: 0.25
   3. pm2.5: 0.20
   4. hour: 0.12
   5. county: 0.08
   ```
3. **OOB 分數**（Out-of-Bag Score）

### 2.4.4 與期中報告連結

驗證期中觀察：風速與季節應為重要性最高的特徵
