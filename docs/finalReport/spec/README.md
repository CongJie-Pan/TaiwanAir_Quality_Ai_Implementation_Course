## 專案簡介

延續期中報告的發現（風速與 AQI 關係、季節性變化），應用三個 AI 模型進行驗證與預測分析。

**期中報告核心發現**：
1. AQI 隨風速增加而下降
2. 冬季污染較嚴重（季節性變化）
3. 低風速時才會出現「對敏感族群不健康」等級

**期末目標**：從「觀察」延伸到「建模與預測」
